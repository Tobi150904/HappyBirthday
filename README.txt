BẢN GHÉP 3 PHẦN
================
Thứ tự chạy:
1) Phần sinh nhật (lovegift-birthday-clone-v3) - đã bỏ 2 cảnh cuối "keepsake" và "share"
2) Phần "Giữ để bắt đầu" (2-canh-dau-source-goc) - thư mục intro/
3) Phần trái tim 3D (heart-love-3d) - thư mục heart/

Cách chạy: cần mở bằng một máy chủ web (không mở trực tiếp file).
Ví dụ: mở terminal tại thư mục này rồi chạy
    python3 -m http.server 8080
sau đó vào http://localhost:8080

Điểm nối nằm ở file merge-bridge.js (đã chèn vào cuối index.html).
